# Weather NLP Seed Dataset

This is a SMALL BASELINE dataset for the Weather NLP project.

Tasks:
1. Language classification: 10 languages
2. Intent classification: 7 weather intents
3. Entity extraction: LOCATION, DATE, WEATHER_ATTRIBUTE

Languages:
en, hi, bn, ta, te, mr, gu, kn, ml, pa

Intents:
weather_current
weather_forecast
temperature
humidity
rain
wind
air_quality

Important:
- This seed set is intentionally small (140 examples total) and should NOT be treated as production training data.
- Some examples are synthetic translations/templates. Human review by native speakers is recommended before serious training.
- The next step is to inspect/correct the examples, then expand the dataset substantially.
